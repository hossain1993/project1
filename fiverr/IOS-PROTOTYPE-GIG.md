## FAQs

### Is this a real iOS app or a Figma design?

It is a runnable native iPhone prototype built with SwiftUI and delivered as an Xcode project. The standard package uses local sample data and focuses on the front-end experience.

### What do you need from me to get started?

Please send the app goal, target user, required screens, primary user flow, final text, logo and colors if available, and two or three apps whose style or interaction you like.

### Can you connect a backend, login, payments, or an API?

Those features are outside the standard package. Message me before ordering so I can review the data, security, testing, account, and service requirements before providing a custom quote.

### Will you publish the app to the App Store?

App Store submission is not included in the standard prototype package. The delivery is a simulator-tested Xcode project and source code. TestFlight or App Store work requires a separate scope review and the client’s own Apple Developer account.

### How many screens and revisions are included?

The package includes up to 5 custom iPhone screens, one focused user flow, and two revision rounds. An additional screen is $125 and adds two delivery days.

## Buyer requirements

Mark these questions as required:

1. Describe the app idea, target user, and the main task the user should complete in the prototype.
2. List up to 5 screens and describe the action or information required on each screen.
3. Provide finalized text, logo, colors, images you have permission to use, and two or three reference apps. If something is unavailable, list what is missing.
4. Describe the single interactive user flow from its starting screen to its final confirmation or result.
5. List any backend, login, payment, API, notification, TestFlight, or App Store requirement. These are not included in the standard package and must be reviewed before ordering.
